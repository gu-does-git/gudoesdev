Interactive Japanese language learning platform designed for performance and mobile optimization. Features static lesson pages with interactive exercise components, making it fast and responsive across all devices.

Key Features:
- Static-first architecture with Astro.js for blazing fast load times
- Interactive drill components for verb conjugation practice
- Mobile-optimized with focus on core learning UX
- Expandable framework structure for additional drill types
- Clean conventional commits enforced with Husky + Commitlint
