Plataforma interativa de aprendizagem de japonês projetada para performance e otimização mobile. Possui páginas de lição estáticas com componentes de exercícios interativos, tornando-a rápida e responsiva em todos os dispositivos.

Principais Recursos:
- Arquitetura static-first com Astro.js para carregamento extremamente rápido
- Componentes de exercícios interativos para prática de conjugação verbal
- Otimizado para mobile com foco na experiência de aprendizado
- Estrutura de framework expansível para tipos adicionais de exercícios
- Commits convencionais limpos com Husky + Commitlint
